# IFPSI – Instituto de Formación Profesional San Isidro

## Sitio web

https://antofigueira18-afk.github.io/Figueira-PrimerPreEntregaCss/

## Descripción del proyecto

**IFPSI** es un sitio web institucional desarrollado para un instituto ficticio de formación profesional, fundado en 2006 y dedicado a la capacitación en entrenamiento físico, fitness y bienestar.

El objetivo del proyecto es presentar múltiples páginas `html` con una base semántica correcta, haciendo foco principalmente en el estilado de las mismas.

## Páginas del sitio

El sitio web está compuesto por cinco páginas:

- **Inicio (`index.html`):** Presentación general de la institución y acceso a sus principales secciones.
- **Sobre nosotros (`sobre-nosotros.html`):** Información sobre la historia, misión y compromiso del instituto.
- **Cursos (`cursos.html`):** Presentación de la oferta académica.
- **Preguntas frecuentes (`preguntas-frecuentes.html`):** Respuestas a consultas frecuentes y formulario de contacto.
- **Cómo llegar (`como-llegar.html`):** Información sobre la ubicación del instituto y como llegar al mismo.

## Tecnologías utilizadas

- `HTML5`
- `CSS3`
- `Sass (SCSS)`
- `Git`
- `GitHub`

## Frameworks y librerías

- Bootstrap 5.3.8
- AOS (Animate On Scroll)

## Características del proyecto

- Diseño responsive con enfoque **mobile first**.
- Navegación entre las distintas páginas.
- Adaptación a diferentes tamaños de pantalla mediante `media queries`.
- Animaciones y transiciones.
- Organización de estilos mediante parciales de `SCSS`.
- Uso de componentes de **Bootstrap**.
- Animaciones al desplazarse por la página mediante **AOS**.
